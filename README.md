# NestCraft Next.js Conversion

This project was converted from a Vite + React + TypeScript app to a Next.js App Router project.

## Run locally

```bash
npm install
npm run dev
```

## Routes

- /
- /shop
- /category/[id]
- /product/[id]
- /about
- /services
- /blog
- /faq
- /contact
- /cart
- /checkout

## Documentation classification

NestCraft is a controlled reference, not an active Kalp platform authority.
When its documentation is registered, it must be classified as reference
material and processed through the
[Kalp central documentation system](../kalp-admin/docs/platform/knowledge/CENTRAL_DOCUMENTATION_SYSTEM.md).
