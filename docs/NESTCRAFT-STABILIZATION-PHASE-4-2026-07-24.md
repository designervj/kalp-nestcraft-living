## Test-runner decision

Vitest `4.1.10` was selected because:

- its declared engine supports Node 22;
- it executes TypeScript without an additional compiler adapter;
- it provides module isolation, hoisted dependency mocks, and deterministic
  non-watch execution;
- the existing `@/*` alias can be mapped directly in one config entry;
- route handlers can be called directly with the Node test environment;
- the required tests need neither a browser DOM nor React component rendering.

Only Vitest was added. Supertest, MSW, jsdom, React Testing Library, Playwright,
and coverage packages were not needed.

The suite runs serially with isolated modules:

```text
npm test -> vitest run
```

The command exits non-zero on any failing test.
